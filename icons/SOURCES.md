# Icon sources

The Rust icon was developed from the Rust icon in Catppuccin Icons, with changes to the silhouette, claws, eyes, legs, color and an added R.

Source: https://github.com/catppuccin/vscode-icons/blob/main/icons/mocha/rust.svg
Upstream license: MIT, reproduced in `LICENSE-catppuccin`.

Folder, Go and JSON SVGs were drawn for Neon Moss. The Go icon depicts a gopher.
